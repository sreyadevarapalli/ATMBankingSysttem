# ATM Banking System (Java Console Application)

A console-based **ATM Banking System** developed using Java.
This project demonstrates core Object-Oriented Programming concepts along with file handling, serialization, and custom exception handling.

---

## 🚀 Features

* Create new bank account
* Deposit money
* Withdraw money
* Check account balance
* Search account details
* Persistent data storage using Serialization
* Custom exception handling for safe transactions

## ▶️ How to Run

### Using VS Code / Eclipse

1. Open the project folder
2. Navigate to `src/main/ATMBankingSystem.java`
3. Run the file

### Using Terminal

```bash
javac src/**/*.java
java src.main.ATMBankingSystem
```
